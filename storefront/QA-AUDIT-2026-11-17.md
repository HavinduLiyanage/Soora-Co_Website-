# Soora & Co. QA audit — 17 November 2026

Scope: customer storefront and owner dashboard. Testing combined real browser interactions, isolated PostgreSQL HTTP integration tests, domain/schema tests, source review, and a public route/image crawl. This is not a claim that every button has been exercised on every browser/device.

## Fixes
- Confirmation dialogs now render within the dashboard, support Escape/Cancel, and default focus to Cancel.
- Sale and campaign datetime fields capture input immediately; dates no longer disappear after another field changes. Browser regression verified persistence and schedule validation.
- Separate mobile banner artwork can be enabled before choosing the desktop image.
- Wholesale enquiry now offers Continue to WhatsApp using configured store settings and the edited message; copy remains available.
- Product brand link uses the same URL slug normalization as brand routes (including spaces and punctuation).
- Saving a deleted record as a draft restores it privately instead of leaving it archived. Watch editor explicitly labels this Restore as draft. Regression test verifies preservation of data and lack of public exposure.
- FAQ enquiry answer reflects whether WhatsApp is configured. Contact text no longer incorrectly says live contact is unavailable.
- Next.js updated from 16.4.3 to 16.4.6. Nested Zod under @vercel/cli-config uses the already-patched direct Zod version, rather than downgrading Blob. Production dependency audit reports zero known vulnerabilities.

## Safety and reproducibility
Live catalog was read-only during QA, except for the approved unassigned image uploads (the earlier QA-upload-check.webp API test and this follow-up browser upload of an existing bundled sbtr029.webp photo). Inventory, banner, price, sale and settings mutations used the isolated database on 127.0.0.1:55437. Auth secrets are excluded from source and logs.

Commands: npm test; npm run build:server; npm audit --omit=dev; node --env-file=.cache/admin-test.env scripts/test-admin-integration.mjs (requires isolated server on port 3001); node scripts/audit-public.mjs.
